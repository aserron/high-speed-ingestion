# Utility Scripts

This directory contains utility scripts organized by category for better maintainability.

## Directory Structure

- `github/` - GitHub-related automation scripts (PRs, issues, projects)
- `deployment/` - Deployment and release management scripts  
- `maintenance/` - General maintenance and cleanup scripts
- `development/` - Development workflow scripts

## Usage

All scripts maintain their original functionality. Update any references in documentation or other scripts to point to the new locations under `scripts/utils/`.

## Migration Notes

These scripts were moved from the root directory to improve project organization.
