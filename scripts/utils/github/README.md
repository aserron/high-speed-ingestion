# GitHub Automation Scripts

Scripts for managing GitHub projects, PRs, and issues.

## Scripts

- `create_github_project.ps1` - Creates GitHub project structure
- `create_historical_prs.ps1` - Creates historical pull requests
- `create_historical_prs.sh` - Shell version of historical PR creation
- `create_missing_prs.ps1` - Creates missing pull requests
- `create_issues_*.ps1` - Various issue creation scripts
- `setup_github_project_complete.ps1` - Complete GitHub project setup
